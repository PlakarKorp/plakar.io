

# File Storage

File storage resources represent file systems and shares reached over a network
protocol, whether mounted directly or accessed through a file transfer protocol.
Plakar Control Plane supports the following file storage resources:






## [SFTP](https://www.stg.plakar.io/docs/control-plane/resources/file-storage/sftp/index.md)



## [FTP](https://www.stg.plakar.io/docs/control-plane/resources/file-storage/ftp/index.md)



## [WebDAV](https://www.stg.plakar.io/docs/control-plane/resources/file-storage/webdav/index.md)



## [SMB](https://www.stg.plakar.io/docs/control-plane/resources/file-storage/smb/index.md)



## [NFS](https://www.stg.plakar.io/docs/control-plane/resources/file-storage/nfs/index.md)
