

# File Storage

File storage resources represent file systems and shares reached over a network
protocol, whether mounted directly or accessed through a file transfer protocol.
Plakar Control Plane supports the following file storage resources:






## [SFTP](https://www.plakar.io/docs/control-plane/resources/file-storage/sftp/index.md)



## [FTP](https://www.plakar.io/docs/control-plane/resources/file-storage/ftp/index.md)



## [WebDAV](https://www.plakar.io/docs/control-plane/resources/file-storage/webdav/index.md)
