## New

- `format=directory` dumps each database with `pg_dump -Fd`, one file per  
  table, using `parallel_dumps` jobs. Files are streamed into the snapshot, so
  no local disk is used. This speeds up backups of databases with several large
  tables. Linux only, with FUSE. These snapshots cannot be restored by the
  integration yet. Restore them to a filesystem or mount them with
  `plakar mount`, then run `pg_restore`.
- `exclude_tables` leaves tables out of the dump. `exclude_table_data` keeps
  their definition and leaves out their rows.

## Fixes

- The VFS cache is disabled for logical dumps, which fixes a deadlock when
  backing up with `format=directory`. This needs a Plakar release later than
  v1.1.8. With v1.1.8 and earlier, run `plakar backup -cache no` instead.

## Security

- The globals file is run by `psql`, which executes `\!` shell commands. Do not
  restore untrusted snapshots, or set `no_globals=true`.
