## Security

- `auth_token` is refused over plain HTTP unless `insecure=true` is also set.
- Redirects from HTTPS to HTTP are rejected, so a connection can no longer be
  downgraded to plain HTTP.
- Error responses from the server are bounded in size and sanitized before they
  are reported.

## New

- The `timeout` option limits how long each request may take. It accepts a
  duration such as `30s` or `10m`, and defaults to 5 minutes.

## Fixes

- Cancelling an operation now stops its pending HTTP requests.
