## Security

- Credentials are now refused when `tls_no_verify=true` is set, unless
  `insecure=true` is also set. Credentials embedded in the URL, such as
  `http://user:pass@host`, are covered by the same check.
  ([#216](https://github.com/PlakarKorp/integrations/pull/216))
- Redirects to a different host are rejected. Before, only a redirect from HTTPS
  to HTTP was refused.
  ([#221](https://github.com/PlakarKorp/integrations/pull/221))
