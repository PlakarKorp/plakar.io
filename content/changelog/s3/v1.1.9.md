## Security

- Opening a store now rejects a `CONFIG` object larger than 2 KB. Before, it was
  read with no size limit, so a malicious or misbehaving server could force
  unbounded memory use.
  ([#265](https://github.com/PlakarKorp/integrations/pull/265))

## Fixes

- Creating a store on Garage no longer fails with `Unimplemented action`. A
  backend that does not implement Object Lock is now treated as having no Object
  Lock configured. ([#268](https://github.com/PlakarKorp/integrations/pull/268))
