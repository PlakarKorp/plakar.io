## New

- PVCs can be excluded from backup using ignore patterns.
- Restore supports namespace remapping: when targeting a specific namespace,
  global resources are skipped and existing resources are rewritten to land in
  the target namespace.
- Inventory emits entries for the cluster and individual namespaces, enabling
  namespace-scoped backups from the Plakar Control Plane.
- Generated resources are no longer excluded from backups (they remain excluded
  from the inventory for now).

## Fixes

- `kubeconfig_file`, `kubeconfig`, and `labels` parameters are now looked up
  correctly, allowing the integration to run on Plakar edges deployed inside the
  target cluster.
- Restore correctly drops the resource version, removes the cluster IP from
  Services, skips PersistentVolumes, removes the PV link when restoring PVCs,
  and excludes Endpoints.
