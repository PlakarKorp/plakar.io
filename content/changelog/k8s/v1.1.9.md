## Security

- Pod communication is secured with mutual TLS (mTLS).
- `automountServiceAccountToken` is set to `false` on created pods.

## New

- A readiness probe is added to the created pod.
- RBAC permissions are documented with an example `rbac.yaml`.
- PVCs with `volumeMode: Block` are explicitly rejected (not yet supported).

## Fixes

- Resources created during backup are now correctly deleted when the context is
  cancelled.
- No service is created alongside the pod.
- `Ping()` uses a `SelfSubjectAccessReview` instead of fetching the namespace,
  reducing required permissions.
- Error handling is improved during resource listing and pod startup.
- An upper bound is set for the pod to come online, preventing indefinite waits.
- PVC creation from a `VolumeSnapshot` is more reliable.
