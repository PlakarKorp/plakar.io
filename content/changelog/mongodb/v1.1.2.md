## New

- `database` backs up a single database instead of the whole server. A user
  without read access to `admin` can now back up the databases it can read.
- `auth_database` sets the database that holds the user's credentials, on the
  source and the destination.

## Fixes

- A race when reading the output of `mongodump` and `mongorestore` could fail a
  backup or a restore with an empty error. A failed `mongodump` no longer leaves
  a truncated dump stored as complete.
- A restore no longer panics when `mongorestore` exits early, for example on an
  authentication failure.
- Cancelling a backup or a restore now stops `mongodump` and `mongorestore`.
