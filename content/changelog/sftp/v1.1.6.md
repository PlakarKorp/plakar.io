## Security

- Restores verify that every path stays inside the restore root.
- Stores enforce `0700` permissions on Kloset subdirectories.
- The new `host_key` option verifies the server against a given host key entry.

## Improvements

- Restores of large files are faster, using concurrent transfers.
- The SSH control socket is created in `XDG_RUNTIME_DIR`, or in the user's local
  cache directory.
- The integration was reworked and simplified.

## Fixes

- Cancellation errors are reported correctly.
- Failures to start the SSH master connection are reported, along with the
  command that was attempted.
