## New

- The destination connector accepts a `skip_permissions` option to restore
  without setting permission bits.

## Improvements

- A store checks for the `posix-rename@openssh.com` extension when connecting
  and fails early if the server does not support it.
- Restores use `posix-rename` when the server supports it, so existing files are
  replaced atomically.

## Fixes

- With `set_owner`, restored files are given their owner before their mode, so
  setuid and setgid bits are no longer cleared.
