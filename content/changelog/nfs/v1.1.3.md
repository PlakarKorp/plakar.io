## Security

- Directories that a restore creates to reach an entry, rather than from the
  snapshot, get mode `0700` instead of `0755`.

## Fixes

- A restore replaces an existing file at the same path. Before, a restored file
  shorter than the existing one kept the end of the old content.
- A truncated or rejected reply from the server fails the operation instead of
  crashing Plakar.
