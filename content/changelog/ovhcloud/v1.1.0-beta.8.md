## Breaking changes

- The `ovh-instance` and `ovh-block` connectors are removed. Back up and restore
  OVHcloud Public Cloud instances and volumes with the
  [OpenStack integration](/docs/community/main/integrations/ovhcloud/) instead.

## Fixes

- The Secret Manager connection test no longer fails on every OKMS domain. It
  now lists the secrets of the domain, which checks the credentials and the OKMS
  ID in one call.
