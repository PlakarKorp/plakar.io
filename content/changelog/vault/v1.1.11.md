## Security

- Using `insecure=false` no longer switches the connection to plain HTTP. An
  empty value keeps HTTPS, boolean values are respected, and any other value is
  an error.

## New

- The secret provider checks that Vault is initialized and unsealed, and that
  the token is valid.

## Fixes

- `force=false` or `0` no longer forces a restore. `force` is parsed as a
  boolean, and any other value is an error.
- The secret provider's "key not found" error now names the missing key.
