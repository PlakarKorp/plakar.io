## New

- Back up Cinder block storage volumes with the new block storage importer.
- Restore Cinder volumes using the `openstack-block` exporter.
- Back up Nova server instances with the new Nova importer.
- Restore Nova servers using the `openstack-instance` exporter.
- Block storage backups now create a placeholder inventory record on spawn.

## Fixes

- Improved backup reliability for block storage, including correct handling of
  encrypted volumes.
