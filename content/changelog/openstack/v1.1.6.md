## Fixes

- Nova server backups no longer reuse stale cached data. Their entries now carry
  the time of the backup instead of a fixed date.
  ([#354](https://github.com/PlakarKorp/integrations/pull/354))
- Attached volumes are now found when the server exposes them as virtio-scsi
  devices, or names them with the full volume ID.
  ([#355](https://github.com/PlakarKorp/integrations/pull/355))
