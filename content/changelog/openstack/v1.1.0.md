## New

- First release of the OpenStack integration.
- Inventory lookup across all supported resource types.
- Authentication via username/password or application credentials.
- Backs up and restores the following resource types:
  - **Nova**: compute instances.
  - **Cinder**: block storage volumes.
  - **Swift**: object storage containers.
  - **Trove**: managed databases.
  - **Glance**: images.
