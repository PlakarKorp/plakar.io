## New

- Added `Destination` CRD for destination connectors.
- Added `FieldsFrom` and `FieldValue` fields to `Source` and `Store` specs.
- Introduced `ScheduleSync`, `ScheduleCheck`, and `Restore` CRDs for task
  scheduling.
- Added multi-group support for CRD organisation.
- Scaffolded a distributable Helm chart.
- Login to the Plakar control plane now uses API keys.
- Added API reference documentation, generated and published in CI.
- Sample manifests added for every CRD.

## Improvements

- Connector reconciliation logic refactored into a shared generic function.
- Connector spec updates are now propagated to the control plane via
  `UpdateConnector`.
- `ScheduleBackup` updates the task in the control plane when the spec changes.
- Replaced `Has` + `Update` calls with a single `SyncConnector` to avoid a
  redundant `GET`.
- `plakman`: actor is now set for scheduler interactions.
