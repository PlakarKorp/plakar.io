## New

- Added `Restore` CRD type for orchestrating restore operations.
- Added `TaskRun` CRD to report the status of individual task executions on Kubernetes.
- Added `HistoryLimit` field to `ScheduleBackup`, `ScheduleSync`, `ScheduleCheck`, and `Restore` CRDs to control how many `TaskRun` records are retained (default: 5).
- Added `EdgeTags` to `ScheduleBackup`, `ScheduleSync`, `ScheduleCheck`, and `Restore`.
- Added `observedGeneration` to connector specs.
- Connectors are tested for reachability on create and update.

## Improvements

- Sync is skipped when the connector generation is unchanged, avoiding redundant reconciliation cycles.
- `Plakar.spec.inventoryUUID` is now optional; the operator creates one automatically when it is unset.
- The operator uses the user-configured scheduler instead of hardcoding `"custom"`.

## Breaking changes

- `Version` field removed from the `Integration` CRD spec.
- Only a single `Plakar` resource is accepted per namespace for now; extra resources are rejected.
