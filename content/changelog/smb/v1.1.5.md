## Breaking changes

- A restore refuses to write through a file or directory that already exists in
  the restore root. Restore into a new, empty directory instead.

## Security

- A restore can no longer be redirected outside the restore root by a symlink
  already present on the share. Such symlinks are resolved by the server and can
  be hidden from the client by older Samba versions.
