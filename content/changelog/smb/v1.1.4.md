## Breaking changes

- SMB message signing is now required. Connections to a server that does not
  sign messages fail, instead of falling back to unsigned traffic that could be
  altered in transit. Enable signing on the server before upgrading.

## Security

- A restore refuses entries whose name or symlink target contains a backslash,
  which the server treats as a path separator and which could otherwise place a
  file outside the restore root.
- A restore refuses a file that would take the place of the restore root itself.
