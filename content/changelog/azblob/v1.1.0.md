## New

- Back up Azure Blob Storage containers, or prefixes within them, and restore
  snapshots into containers.
- Host a Kloset store in an Azure Blob Storage container.
- Authenticate with a connection string, an account name and key, or an Azure
  managed identity, system-assigned or user-assigned. Public containers and
  emulators such as Azurite can be reached without authentication through a
  custom endpoint.
