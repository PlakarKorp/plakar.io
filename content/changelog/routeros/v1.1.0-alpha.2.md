## Security

- Credentials are redacted from errors reported about the location.
- The device's host key is verified. It can be given with `host_key`, or read
  from the file set with `known_hosts_file`, which defaults to
  `~/.ssh/known_hosts`. `insecure_ignore_host_key` accepts any host key.

## New

- The SSH agent is used automatically when `SSH_AUTH_SOCK` is set.
- Connector options are described by a schema.

## Fixes

- `private_key_passphrase` is now applied correctly when unlocking a private
  key.
