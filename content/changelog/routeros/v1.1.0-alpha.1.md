## New

- Back up the text export of a RouterOS device configuration as a `.rsc` file
  with the `routeros+export` protocol.
- Back up a RouterOS system backup with the `routeros+backup` protocol.
- Restore a `.rsc` text export with the `routeros` protocol. The `dry_run`
  option evaluates the file without applying it.
- Connect over SSH with a password or a private key, optionally protected by a
  passphrase.
