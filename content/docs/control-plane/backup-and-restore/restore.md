# Restoring Data

On the **Restore** page, under **Backup & restore**, restore points can be
narrowed down by creation date, by store and by label. A restore point held by
several stores, for example after a sync, is restored from the store you pick.
The whole restore point can be restored, or a single file or folder found by
browsing or searching its contents. A restore takes the same options as a
[restore task](../../scheduling/tasks#restore-task).
