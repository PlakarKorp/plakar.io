# Checking Stores

A check, started from **Backup & restore** > **Check**, covers all the restore
points of a store, the recent ones, or a single one. It verifies the restore
points themselves, unlike the
[integrity checks](../../apps/stores#integrity-checks) that run continuously on
a store. See
[when to use integrity checks and check tasks](../../apps/stores#when-to-use-integrity-checks-and-check-tasks).
A check takes the same options as a
[check task](../../scheduling/tasks#check-task).
