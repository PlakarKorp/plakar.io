# Managed Inventories

A managed inventory connects Plakar Control Plane to a cloud provider or
platform and discovers its resources automatically. Each page covers the
credentials and permissions the provider needs, and the resources it discovers.

For resources that no provider discovers, use a
[self-managed inventory](../self-managed).
