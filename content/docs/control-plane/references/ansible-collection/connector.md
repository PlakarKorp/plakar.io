# connector

Written `plakarkorp.plakar.connector` in a task.

Manage Plakar source and destination connectors.

Creates, updates and deletes source and destination connectors in the Plakar
management API. For stores, use `plakarkorp.plakar.store` instead.

Connectors are matched by name within the organization; the name is the
playbook's key, so it must be unique per connector type.

Only the options the playbook sets are managed on update; anything else keeps
its current server-side value.

## Examples

```yaml
- name: SFTP source for the web tier
  plakarkorp.plakar.connector:
    name: Web tier
    type: source
    protocol: sftp
    integration: sftp
    resource: urn:res-grateful-cascade
    environment: production
    data_classes: [filesystem]
    fields:
      username: tunnel
      root: /home/tunnel/data
      port: 2222

- name: Retire it
  plakarkorp.plakar.connector:
    name: Web tier
    type: source
    state: absent
```

## Options

| Option            | Type        | Required | Default     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------- | ----------- | -------- | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `api_key`         | str         | No       |             | API key of a service account, as minted by the Plakar API (`pcp_ak_...`). API keys authenticate without a second factor and are bound to one organization. The service account must hold a role in the organization (the `operator` role suffices for running backups and restores); without a grant the API answers with empty lists rather than errors. Falls back to the `PLAKAR_API_KEY` environment variable.                                                                                                                                                                                                                                                                                 |
| `api_url`         | str         | No       |             | Base URL of the Plakar management API, for example `https://plakar.example.com`. Falls back to the `PLAKAR_API_URL` environment variable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `data_classes`    | list of str | No       |             | Data classes the connector carries. Sources only. The Control Plane refuses them on a destination, and so does the module.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `endpoints`       | list of str | No       |             | Endpoint names the connector reaches its resource through.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `environment`     | str         | No       |             | Environment label, for example `production`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `fields`          | dict        | No       |             | Integration-specific configuration, as a mapping of field name to value. To take a value from a secret provider instead, give a mapping with `value`, the path of the secret in the provider, and `provider`, the name of the secret provider as `plakarkorp.plakar.secret_provider` declares it. `provider_id` takes its id instead of its name. On update, only the fields named here are compared and replaced; other existing fields are preserved.                                                                                                                                                                                                                                            |
| `integration`     | str         | No       |             | Name of the installed integration backing the connector, for example `s3` or `sftp`. Required when creating; immutable afterwards. Naming another one for an existing connector fails the task.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `name`            | str         | Yes      |             | Name of the connector.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `organization_id` | str         | No       |             | UUID of the organization to operate in, when different from the one the API key is bound to. The badge is re-scoped once per organization and cached for the duration of the task.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `protocol`        | str         | No       |             | Protocol spoken to the resource, for example `s3` or `sftp`. Defaults to the integration name, which matches for the standard integrations; set it only when they differ.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `resource`        | str         | No       |             | URN or name of the inventory resource the connector attaches to. Required when creating; immutable afterwards. A URN and a name for the same resource are the same resource, and naming another one for an existing connector fails the task. A connector whose resource was deleted since, by hand or by a sync after it disappeared from the cloud, is left without one. The Control Plane then refuses any change to it but a new resource, which it takes in place.                                                                                                                                                                                                                            |
| `state`           | str         | No       | `present`   | Whether the connector should exist. One of `present`, `absent`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `temperature`     | str         | No       |             | Refused when set. The Control Plane only accepts a temperature on a store.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `timeout`         | int         | No       | `30`        | Timeout in seconds for each individual API request (not for job completion; the action modules have `wait_timeout` for that).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `type`            | str         | Yes      |             | What the connector is used for. One of `source`, `destination`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `update_secrets`  | str         | No       | `on_create` | When to send a value the API does not show. Since v0.19 the Plakar Control Plane leaves the value of a sensitive field out of what it returns, so the module cannot tell whether the one in the playbook differs from the one stored. `on_create` sends such a value at creation only. Later runs leave the stored one alone and report no change for it, also when another option of the same task is updated. `always` sends it on every run, which then reports a change each time. Use it for the run that rotates a credential. A value that references a secret provider is always shown, and so always compared, as is every value on an older Control Plane. One of `on_create`, `always`. |
| `validate_certs`  | bool        | No       | `true`      | Whether to validate TLS certificates when talking to the API.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |

## Returns

| Key         | Type        | Returned                                 | Description                                                      |
| ----------- | ----------- | ---------------------------------------- | ---------------------------------------------------------------- |
| `connector` | dict        | when the connector exists or was created | The connector acted on (a summary; field values are not echoed). |
| `diff_keys` | list of str | on update                                | The option names whose values differed and drove the update.     |
