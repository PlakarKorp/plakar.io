Resilience as Code

Backup is no longer a side process.
Drive it from the tools that run your platform.

Each team protects its data with its own tools. Declare stores, sources, and schedules in code, review them like any other change, and let the Control Plane run them across the estate.

nightly backup, as code

A ScheduleBackup resource, applied with kubectl or your GitOps tool.

apiVersion: task.plakar.io/v1alpha1
kind: ScheduleBackup
metadata:
  name: nightly-database-backup
spec:
  periodicity: 86400
  source:
    name: production-database
  store:
    name: production-s3

Kubernetes operator docs

The same schedule with the plakarkorp/plakar provider.

resource "plakar_schedule" "nightly" {
  name      = "Nightly database backup"
  type      = "backup"
  origin_id = data.plakar_connector.db.id
  target_id = plakar_store.offsite.id

  rule {
    periodicity = 86400
  }
}
